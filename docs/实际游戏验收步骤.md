# 《诛仙伏魔录》真机验收

设备：iPhone 17 Pro / iOS 27.0；当前测试版本：J2ME Studio 0.4.2 (6)。用户已反馈方向盘修复后“测试了似乎没什么问题了”，记录为斜向修复初步通过。以下各项尚待用户反馈。使用手机中已有的游戏和存档即可。

## 先测试游戏进度保存

1. 正常玩到能打开游戏自身菜单的位置，记录一个容易辨认的进度，例如人物等级、所在地图或金钱。
2. 使用**游戏自己的“保存/存档”功能**；若游戏只有自动存档，先确认触发条件及保存提示，不能假定模拟器会替游戏保存所有内存状态。若没有找到存档菜单，提供当前游戏菜单截图后再决定下一步。
3. 保存完成后，点模拟器顶部“退出”，等待返回游戏库。长按《诛仙伏魔录》，点“备份 RMS 存档”。该快照仍在同一个 App 中，外部备份可按 Windows 指南保存整个 Documents。
4. 再启动同一个游戏，使用游戏自己的“继续游戏/读取存档”，确认刚记录的进度仍在。
5. 再次正常保存并退出到游戏库，随后从 iPhone 多任务界面关闭 J2ME Studio。重新打开同一游戏并读取存档，确认进度仍在。不要以删除游戏或卸载 App 的方式测试。

RMS 是游戏数据存储机制，不是模拟器的即时状态快照；游戏内没有写入的数据不会因为 App 退出就自动变成可恢复的存档。当前回归已验证自编诊断的 RMS，但商业游戏的保存时机和数据格式仍需这次实际验证。

## 再测试恢复、声音与持续运行

1. 在已保存进度的位置，切回 iPhone 桌面约 30 秒，再回到游戏。检查画面、移动、技能及按键释放，避免出现自动持续移动或必须重开才能操作。
2. 再保存一次进度，锁屏约 30 秒，解锁回游戏，重复上述检查。系统如回收 App，应确认能够重新启动并读取已保存进度，不将系统终止误记为内存现场保持成功。
3. 在有背景音乐或技能音效的场景检查声音。确认游戏内音量、手机音量和静音设置；若无声，记录具体场景及是否只有音乐或只有音效缺失。自编诊断没有音频资源，不能代替这一项。
4. 继续正常游戏 10–15 分钟，包含走动、技能及游戏允许的切换地图或战斗；记录卡死、闪退、明显掉帧或声音异常的触发场景，完成后正常保存。

遇到异常先保留当前数据，在游戏库长按游戏选择“导出运行日志”，记录复现步骤、时间及画面；分享前检查个人信息。不要先清除游戏数据。按专项结果继续修复真实兼容问题，全部基本验收完成后，再推进单游戏专用配置与独立 App；商业资源的使用和分发权限仍需确认。
