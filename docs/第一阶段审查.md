## 调用关系

`AppsListViewController` → `GameViewController.runMIDlet` → `jvm_bridge_init/run_midlet` → miniJVM `call_main(javax/microedition/shell/MIDletRunner)` → Java MIDlet 生命周期及事件队列。

`jvm_bridge_init` 以 `minijvm_rt.jar` 建立 bootclasspath，以 `j2me_api.jar:游戏.jar` 建立 classpath，注册 render/input/ui/audio/M3G/MascotCapsule 原生方法。Java API 经本地方法回到 C/Objective-C，画面由 Swift UIKit 承载。RMS 使用 `app.save.root/rms`。iOS 分支在 `jit.h` 中禁用 JIT，保留字节码解释器。

## 后续风险（已定位，留在对应阶段处理）

- 原版以去扩展名后仅保留 ASCII 字符的文件名作为游戏数据 ID，不同中文文件名可能映射到相同 ID；第二阶段需稳定唯一 ID、迁移和隔离测试，不能直接承诺现有存档隔离可靠。
- 原 Java API 存在 `UnsupportedOperationException`/TODO；RMS 实例由实现类返回，需要按实际调用验收，不能仅看接口基类判断所有 RMS 都不可用或已完整可用。
- 原生线程退出、暂停恢复、多键、中文字体、3D 和音频均需真机验证。
- 现有 UI 仍为上游英文；本阶段仅修改应用名称和构建配置，不冒充完整中文 UI 已完成。
- 启动类库缺少二进制内许可证元数据；候选源码与二进制对应关系以及 M3G/SoundFont 分项义务需进一步整理，详见第三方声明。
