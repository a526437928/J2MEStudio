## 组合诊断的实际错误

原版 `JoystickView.sectorCodes` 将方向盘右侧映射为数字 6，即键码 54，保留八方向数字映射以兼容原游戏。诊断程序只把 -4 识别为右方向，导致实际 54 + 53 无法把 combo 置为 true。此前模拟器直接向 KeyInputController 注入 -4 / 53，因此没有覆盖生产方向盘映射。

新增 HostDiagnosticInputSmoke 使用实际诊断 Canvas，修复前真实失败为 `Right + 5 must recognise direction keycode 54`。修复后，数字 6 和独立导航右键均能组合，按下顺序、释放、同方向两个来源，以及顺序单点和其他方向的反例通过。没有改动方向盘原映射，也没有把结果固定为成功。

0.4.1 的 iOS 自动运行通过方向盘实际角度/分区计算以及数字键 UIButton target/action 合成输入，并断言 Java 收到的右方向键码为 54。它仍不能代替实体 iPhone 的触摸命中、双指操作及系统手势验证。
