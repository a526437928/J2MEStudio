# 0.4.2：斜向误触数字技能修复

用户已在实体 iPhone 上运行本地《诛仙伏魔录》，反馈摇杆左上会释放数字 1 对应的技能。此前方向盘的八个扇区为 6、9、8、7、4、1、2、3，因此斜向与游戏数字技能键发生冲突。这是模拟器默认映射的兼容性问题，不是要求用户修改商业游戏。

## 实现

- 默认“数字方向”模式：正方向仍为 2/4/6/8，左上按 2+4、右上按 2+6、左下按 8+4、右下按 8+6，不从方向盘发出 1/3/7/9。
- “独立方向”使用专用的上/下/左/右键，斜向也为两方向组合，供需要专用方向键的游戏选择。
- “旧八向”保留原先 1/3/7/9 的斜向方式，供依赖该映射的游戏选择。
- 游戏内“设置 → 显示与按键 → 方向盘模式”按游戏保存；右侧数字按钮继续保留所有技能数字键。
- 方向盘记录按住的键集合，扇区切换只发送差异。例如左上到正上只释放左键，上键持续保持；取消、编辑、旋转或失去前台时清理方向盘持有状态，仍沿用原 KeyInputController 的来源计数。
- 0.4.1 配置未包含 directionMode 时，采用新的默认模式，同时保留屏幕方向、缩放、大小、透明度和自定义键位；独立游戏配置支持同一选项。游戏 UUID、JAR、RMS 路径与运行核心不改写。
